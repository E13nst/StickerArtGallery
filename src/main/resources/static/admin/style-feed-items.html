Сброс для текущего админа

По вашей сессии в админке (Telegram ID из initData): очистятся только ваши лайки/дизлайки ленты style feed и связанные строки истории свайпов этой ленты. Другие пользователи и лайки стикерсетов не затрагиваются.

Сброс по user id (любой пользователь)

userId — Telegram ID (как в users.id). Удаляются только ваши строки в ленте и связанные записи свайпов style feed; счётчики на карточках пересчитываются.

QA: повторный показ оценённых карточек (без очистки БД)

Для указанного Telegram user id лента и колода снова показывают карточки, которые вы уже лайкнули/дизлайкнули. Настройка хранится в БД (gallery_kv_settings). Если записи нет — используется env STYLE_FEED_QA_REPEAT_RATED_TELEGRAM_USER_ID. Если в БД сохранено 0 — режим выключен и env игнорируется.
